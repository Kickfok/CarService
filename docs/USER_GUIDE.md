# Руководство пользователя Car Service

Руководство описывает работу с программой Car Service: вход, просмотр каталога услуг, поиск, фильтрацию,
а также добавление, редактирование и удаление услуг администратором.

Установка и создание базы данных описаны в [README](../README.md#быстрый-старт).

## 1. Авторизация

<img src="images/01-login.png" width="600" alt="Страница авторизации">

1. Запустите программу. Откроется страница **"Авторизация"**.
2. Введите логин и пароль.
3. Нажмите **"Войти"** или клавишу `Enter`.

Тестовые учетные записи:

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin1` | `admin1` |
| Пользователь | `user1` | `user1` |

Если логин или пароль неверны, появится сообщение **"Неверный логин или пароль."**

## 2. Роли пользователей

| Действие | Администратор | Пользователь |
|---|:---:|:---:|
| Просмотр, поиск и фильтрация услуг | ✅ | ✅ |
| Добавление услуги | ✅ | - |
| Редактирование услуги | ✅ | - |
| Удаление услуги | ✅ | - |

Пользователь не видит кнопок **"Добавить услугу"**, **"Редактировать"** и **"Удалить"**.

## 3. Список услуг

<img src="images/02-services-admin.png" width="700" alt="Список услуг">

После входа открывается страница **"Список услуг"**. Каждая карточка содержит:

- изображение и название услуги;
- стоимость и длительность в минутах;
- для услуг со скидкой: зачеркнутую исходную цену, цену со скидкой, размер скидки и **зеленый фон**.

Над списком отображается счетчик **"Показано N из M"**: сколько услуг подходит под текущие условия
поиска и сколько их всего.

## 4. Поиск, фильтрация и сортировка

Над списком расположены три элемента управления. Список обновляется сразу при изменении любого из них.

| Элемент | Назначение |
|---|---|
| Сортировка | **"По возрастанию цены"** или **"По убыванию цены"**. Учитывается цена со скидкой |
| Фильтр по скидке | **"Все"** или диапазон: 0-5 %, 5-15 %, 15-30 %, 30-70 %, 70-100 %. Нижняя граница входит в диапазон, верхняя нет. Услуги без скидки попадают в диапазон 0-5 % |
| Поиск | Часть названия услуги, регистр букв не важен |

## 5. Добавление услуги

Доступно только администратору.

1. На странице **"Список услуг"** нажмите **"Добавить услугу"**.
2. Заполните поля:

   | Поле | Правило |
   |---|---|
   | Название | обязательно, не должно совпадать с названием другой услуги |
   | Стоимость, руб. | положительное число |
   | Длительность, мин | целое число от 1 до 240 |
   | Описание | необязательно |
   | Скидка, % | необязательно; целое число от 0 до 100 |

3. Нажмите **"Выбрать фотографию"**, чтобы выбрать изображение в формате PNG или JPG (необязательно).
4. Нажмите **"Сохранить"**.

Если данные заполнены неверно, программа перечислит все ошибки сразу:

<img src="images/04-validation.png" width="400" alt="Ошибки при сохранении">

После успешного сохранения появится сообщение **"Услуга добавлена."**, и программа вернется к списку услуг.

## 6. Редактирование услуги

<img src="images/03-edit-service.png" width="700" alt="Редактирование услуги">

1. В карточке услуги нажмите **"Редактировать"**.
2. Измените нужные поля. Правила те же, что и при добавлении.
3. Чтобы заменить изображение, нажмите **"Выбрать фотографию"**. Если новое изображение не выбрано, остается прежнее.
4. Нажмите **"Сохранить"**.

Чтобы выйти без сохранения, нажмите **"Назад"**: изменения не будут записаны в базу.

## 7. Удаление услуги

1. В карточке услуги нажмите **"Удалить"**.
2. Подтвердите удаление кнопкой **"Да"**.

Услугу, на которую уже записаны клиенты, удалить нельзя. Программа сообщит об этом и покажет количество записей:

<img src="images/05-delete-protected.png" width="500" alt="Удаление невозможно">

## 8. Выход из учетной записи

Нажмите **"Назад"** на странице **"Список услуг"**. Программа вернется на страницу авторизации, текущий
пользователь будет сброшен. На странице авторизации кнопка **"Назад"** скрыта.

## 9. Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Enter` | Войти (на странице авторизации) |
| `F11` | Вернуть окну обычный размер |
| `F12` | Развернуть окно на весь экран |
| `Esc` | Закрыть программу |

## 10. Возможные проблемы

**"Не удалось подключиться к базе данных"** при входе. База не создана или строка подключения указывает
на другой сервер. Создайте базу по инструкции из [database/README.md](../database/README.md) и проверьте
параметр `data source` в `App.config` (`CarService.exe.config` рядом с программой).

**"Неверный логин или пароль"** для правильной пары. Убедитесь, что база создана скриптом из папки
`database`: пароли в ней хранятся в виде хешей, и база старого формата с паролями открытым текстом
с этой версией программы не работает.
