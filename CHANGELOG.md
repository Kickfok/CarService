# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.1.0] - 2026-10-04

### Добавлено

- SQL-скрипты схемы и тестовых данных (`database/`) и скрипт `Setup-Database.ps1`: проект запускается
  на локальной машине без доступа к внешнему серверу.
- Хеширование паролей PBKDF2-SHA256 (`UserRegistration/PasswordHasher.cs`); библиотека `UserRegistration`
  подключена к приложению.
- Счетчик "Показано N из M" над списком услуг.
- Защита от удаления услуги, на которую записаны клиенты; дополнительные фотографии услуги удаляются вместе с ней.
- Сообщение о недоступности базы данных на странице авторизации; вход по клавише `Enter`.
- Класс `Roles` с идентификаторами ролей вместо числа `1` в коде.
- 15 новых модульных тестов (всего 23): хеширование паролей, граничные случаи оценки сложности, кириллица.
- Сборка и тесты в GitHub Actions.
- Автоматический релиз по тегу `vX.Y.Z`: архив с программой, скриптами БД и документацией.
- NuGet-пакет `CarService.UserRegistration` в GitHub Packages; проект библиотеки переведен на SDK-формат.
- README, руководство пользователя, описание базы данных, скриншоты, лицензия MIT.

### Изменено

- Строка подключения указывает на LocalDB с проверкой подлинности Windows; логин и пароль внешнего сервера
  удалены из `App.config`.
- Имя контекста и базы записано латиницей (`CarServiceEntities`, `CarService`) вместо имени с кириллической `С`.
- Колонки `User.Login` и `User.Password` - `nvarchar`, `Password` расширен до 128 символов.
- Главное окно увеличено до 1100×720, его размер можно менять; заголовок страницы больше не перекрывает кнопку "Назад".
- Форма добавления и редактирования услуги выровнена по сетке, подписи полей уточнены.
- Кнопка "Назад" скрыта, когда возвращаться некуда; возврат на страницу авторизации сбрасывает пользователя.
- Фильтр по скидке сравнивает округленные проценты, поэтому погрешность `float` не переносит услугу в соседний диапазон.
- `PasswordStrengthCheker` переименован в `PasswordStrengthChecker`; буквы любого алфавита, включая кириллицу,
  учитываются при оценке сложности.
- Изображения услуг перенесены из ресурсов приложения в `database/seed-images` и переименованы латиницей:
  приложение их не использовало, а размер exe уменьшился на 740 КБ.

### Исправлено

- При редактировании услуги поле скидки могло показать значение вида `15,000000001`, и сохранить услугу было нельзя.
- Удаление услуги с записями клиентов завершалось необработанным исключением.
- Ошибка сохранения оставляла в контексте EF несохраненные изменения.
- Опечатки в сообщениях и именах тестов.

### Удалено

- Закомментированный код разового импорта данных с локальными путями `H:\...`.

## [1.0.0] - 2023-09-01

Первая версия: авторизация, список услуг с поиском и фильтрами, добавление, редактирование и удаление услуг.
